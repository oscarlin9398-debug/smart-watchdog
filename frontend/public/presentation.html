問題痛點與 5D 校園多維治理模型

🚨 現行校園與教保稽查三大瓶頸
1. 事後被動滅火： 重大違規（如超收 28 人、黑牌教保員未核備、虐童不當管教）多為事後檢舉或爆料，孩童身心已受傷害。
2. 局處資料孤島： 裁罰歷程、食安食材登錄、政府採購合約、消防公安安檢散落各系統，無法跨維度交叉研判。
3. 稽查人力難以普查： 新北幅員 29 區、逾 1,500 所學校與幼托，專任稽查員難以地毯式全面普查，急需 AI 智慧分流標註。
🎯 獨創「5D 校園多維治理指數」
1. 裁罰法規違規維度 (35%)： 跨年度重大違規、師生比超收、黑牌教保員記點。
2. 班佛採購財務維度 (20%)： 大宗食材與工程標案，導入 Benford's Law 假帳防弊檢定。
3. 社群負面輿情維度 (20%)： Google Places 公開評價與家長留言 NLP 情感分析。
4. 師資異動流動維度 (15%)： 核心師資年度流動率異常、投保在職核備追蹤。
5. 環境公安食安維度 (10%)： 校舍防墜網合格驗證、午餐廚房 48h 留樣履歷。
動態評估結果： 綜合五維權重輸出 0~100 治理指數，自動劃分紅、黃、綠三級監測名單。

項目二 ｜ 數據及資料運用

多源官方數據匯流與核心防弊演算法

📥 四大多源異質官方數據前處理
1. 教育部全國教保資訊網 API：
抓取幼托立案登記許可、核定收托名額、歷史違規處分字號與違反法規法條。
2. 新北市政府開放資料平台 (NTPC Open Data)：
整合新北 29 區公私立高中職、國中、國小規模、學區與營養午餐合約。
3. 政府電子採購網 (e-Procurement)：
擷取大宗食材、設施採購與防墜工程招決標金額數據（供防弊演算法檢驗）。
4. Google Places & Maps API：
即時採集家長真實評分星等（1~5星）、評論則數與最新留言文本。
⚙️ 兩大核心防弊與量化分析模型
📊 班佛定律 (Benford's Law) 財務防弊檢定：
檢定標案首位數字分佈 \(P(d) = \log_{10}(1 + 1/d)\)。若卡方檢定 \(p < 0.05\) 且頻率反常集中於 4、8 或 9，自動識別「刻意拆單」或「人為假帳」財務風險。
💬 NLP 負面情感與違規關鍵字探勘：
比對「超收、體罰、推搡、未核備、拉肚子、髒亂」等負面關鍵詞，提取潛在家長投訴意向，並計算情緒極性值（Polarity Score）。

項目三 ｜ AWS 雲端技術架構 (安全合規)

100% 恪遵大會雲端安全規範檢核清單

🛡️ 大會安全守則 100% 達標檢核
✅ 1. S3 阻斷公用存取 (Block Public Access)：
S3 儲存桶已 100% 啟用「Block Public Access」，嚴禁公網直接下載。僅允許 CloudFront 透過 Origin Access Control (OAC) 簽名讀取前端資源。
✅ 2. 零個人敏感個資安全政策 (No PII)：
全平台僅收錄政府官方公佈之機構名稱、違規處分字號、核定收托人數與公開評論，完全無收集學生、家長或教職員個人私密個資。
✅ 3. 資料庫關閉公開存取 (Private DB Subnet)：
Aurora RDS 資料庫部署於 VPC 私有子網，不配置 Public IP，安全性群組 (Security Group) 僅開放內部後端容器直連。
⚡ Amazon Bedrock 限流與區域規範
✅ 4. Amazon Bedrock 嚴格節流 (RPS ≤ 1)：
嚴格遵守大會 Bedrock 使用規範，後端透過令牌桶 (Token Bucket) 與排程緩衝池機制，將生成請求嚴格限制在每秒 1 次以下，避免 API 配額超標。
✅ 5. 指定主要區域部署 (AWS us-west-2 Oregon)：
完整架構包括 CloudFront 邊緣、Fargate 容器、Aurora RDS 與 Bedrock 皆統一規劃於大會指定之 us-west-2 (Oregon) 主要區域。
✅ 6. 高可用性架構設計 (Multi-AZ)：
容器與資料庫具備跨可用區 (Multi-AZ) 自動容錯轉移能力，確保新北市 468 所校園監測不中斷。

教育局 4 步稽查流程與雙校五維雷達對比

🔄 教育局日常監測四步標準流程 (SOP)
Step 1. 全市宏觀盤點： 儀表板檢視新北 468 所機構分布，掌握 28 所高風險動向。
Step 2. 鎖定高風險未爆彈： 篩選出紅標機構，查看其重大違規超收或財務假帳異常。
Step 3. 雙校雷達深度比對： 挑選同區兩機構進行五維雷達對比，快速識別管理短板。
Step 4. Bedrock 一鍵生成稽查單： AI 自動生成實地突擊稽查手冊，立即指派督導出勤。
⚖️ 雙校五維雷達對比與匿名吹哨者
• 跨學制／同區橫向評估：
支援任意兩校比對（例如：板橋高中 vs 新莊高中 或 海山國小 vs 秀朗國小）。
• 五維雷達圖直觀重疊：
裁罰、班佛財務、社群輿情、師資流動、公安食安 5 軸覆蓋面積一目了然。
• 匿名吹哨者 SHA-256 防偽存證：
提供家長與教保員匿名檢舉管道，系統自動生成唯一 SHA-256 雜湊存證，杜絕吃案或人為竄改。
